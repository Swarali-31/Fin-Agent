# FinAgent sample imports

All five CSV files contain fictional DEMO data, in INR. Create a separate financial profile in Profile for each file. Never mix sample files with personal records.

Flow: Profile → create/select profile (INR) → Expense Analysis → upload CSV → Save and analyze → Budget Planning → Reports. Master Agent can do the analysis, budget and report together. Financial Research additionally needs TAVILY_API_KEY.
